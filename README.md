# Kaveri Foods website

A responsive static website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `kaveri-foods-website` folder.
3. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation, image lightbox and current year
- `assets/` — the five store photos supplied for this website

## Before publishing
Add the store's confirmed address, phone number, opening hours and any social links. Product availability descriptions are general; update them to match the current inventory.
